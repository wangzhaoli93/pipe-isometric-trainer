# 管线空间训练器 (Pipe Isometric Trainer)

一个用于管道工、管工学徒和相关工程人员的交互式学习工具，帮助训练空间想象力、坐标计算能力和单线图识读技能。

项目地址：[github.com/wangzhaoli93/pipe-isometric-trainer](https://github.com/wangzhaoli93/pipe-isometric-trainer)

## 功能特性

### 三维训练器
- **12 个预设案例**：从简单的立管转向到复杂的空间偏移
- **实时 3D 可视化**：基于 Three.js 的交互式三维管道展示
- **等轴投影单线图**：自动生成二维单线图，带地面投影参考
- **坐标练习模式**：隐藏 3D 视图，训练从单线图推算终点坐标
- **铁丝实操模式**：随机出题并隐藏 3D，按起点、转向、标高和终点四项自检后再揭晓
- **案例收藏与错题记录**：支持多学习者档案，独立保存进度
- **草稿与操作恢复**：自动保存当前训练参数，支持撤销、重做和重新打开后继续

### 空间感闯关
- **6级36题**：方向基础、平面转向、标高变化、空间偏移、坐标链和考试图拆解
- **渐进式提示**：每题提供三级提示，使用提示会降低本题得分但不阻止继续学习
- **答案后显示3D**：提交前只看单线图，答题后显示可旋转三维模型逐段核对
- **考试图干扰训练**：加入尺寸线、投影虚线和阴影三角形，训练只沿真实粗实线追踪
- **铁丝弯制自检**：按起点、真实转折、标高和终点四项检查实物模型
- **本地进度与错题复练**：记录36题掌握情况和错题，可按级别重练
- **双比例观察**：示意比例均衡显示各段，真实比例用于核对实际长短关系
- **逐段坐标讲解**：答案揭晓后同步高亮2D与3D管段，展示后点减前点和方向结论
- **图层控制**：可分别显示或隐藏尺寸投影辅助线、坐标点与焊口标记
- **点击路径训练**：从P0开始按顺序点击真实转折点，点击辅助线会即时指出错误

### 图纸识别与3D还原
- **图片和 PDF 导入**：支持 JPG、PNG、PDF，PDF 可翻页并优先读取文字层
- **本地 OCR**：离线识别中文、英文、管线号、DN、坐标和常见尺寸候选
- **中心线标记**：支持自动找长线，也可按管线顺序手工点击转折点
- **路径确认**：逐段校正方向、长度或空间位移后生成训练器 3D 和单线图
- **人工复核原则**：自动结果只作为学习辅助，坐标、尺寸、方向及管件必须对照原图确认

### 专业模块
- **5 大专业方向**：石油管线、化工管线、模块化施工、管道预制、改造与切割
- **20 节系统课程**：每节包含学习要点、操作步骤和现场检查点
- **现场判断题**：模拟真实工程场景的安全与质量判断

### 工程计算器
- **勾股与三角训练**：按已知边、斜边或角度选择公式，动态显示尺寸图、角度、坡度与逐步代入过程
- **典型例题与随机题**：包含3-4-5、45°偏移、30°斜管、2%坡管、空间二次勾股及随机核对
- **直管下料与组对**：区分中心距和坡口端面净距，计算管件占用、对接焊根部间隙、修切余量、工艺补偿及锯缝耗料
- **900 mm 对比例题**：双焊口、单焊口、两端占用和活口留量四种情况配尺寸图与完整算式
- **双平面复合偏移**：计算X/Y合成偏移、滚转角、斜管行程、轴向推进、弯头扣除和中间直管
- **坡度与测点标高**：支持%、‰、mm/m、1:n和角度互换，按间距生成支架或测点标高表
- **空间角度计算**：坐标差计算平面偏移、真长、方向角和坡度
- **来回弯计算**：S 形偏移的斜长、水平占用和弯头切线长
- **弯头下料**：中心半径、切线长、弧长和弦长计算
- **死口/活口闭合**：闭合管段的净下料长度计算
- **斜接弯头**：等角斜接弯头的接缝角度和退切量
- **马鞍口展开**：90° 支管马鞍口的相贯线放样
- **改造对比**：旧管实测与新设计的尺寸对比
- **项目计算续做**：最近记录保存完整输入参数，按项目分类并可一键恢复

### 运行稳定性
- **重资源按需加载**：Three.js、PDF.js 和 OCR 仅在打开相关功能时载入
- **安卓返回键分层处理**：先关闭搜索或计算弹层，再返回上一页，首页二次按键退出
- **学习者数据隔离**：训练草稿、项目记录、进度和错题均按学习者独立保存并参与备份

### 随手算工具
- **表达式计算**：支持三角函数、开方、幂运算
- **圆与圆周**：半径、直径、周长、面积互算
- **直角三角形**：勾股定理和角度计算
- **管道计算**：周长、外表面积、容积和理论重量
- **单位换算**：长度和压力单位转换

### 学习路线
- **30 天学习计划**：四阶段、30个每日任务，从坐标基础到图纸对应现场
- **练习直达**：每一天可直接打开指定微课、空间级别、术语分类、计算器、训练案例或专业课程
- **阶段跟踪**：显示总体进度、下一任务和各阶段完成度，按学习者独立保存并参与备份恢复
- **16 个关键技能点**：可勾选追踪完成进度
- **速查表**：常见缩写、图纸类型和施工标记
- **英文缩写闯关**：每轮随机 10 题，覆盖 ISO、P&ID、DN、SCH、焊口及检测缩写

### 学习教练
- **五类能力测评**：方向坐标、空间识图、几何计算、图纸符号和现场施工
- **错题自动归因**：汇总空间闯关、坐标练习、微课、缩写和专业判断中的错误
- **个性推荐路线**：根据测评分数和最近错误自动排列专项训练优先级

### 现场工作台
- **项目测量记录**：记录管口、坐标点、支架、焊口和标高，可填写设计值、实测值、坐标及备注
- **偏差与复测管理**：按允许偏差自动标记合格或超差，并单独筛选待复测记录
- **离线报告**：计算结果和现场记录可导出HTML，在浏览器中打印或保存为PDF

### 全局搜索
- **快捷入口**：标题栏搜索按钮；电脑可按 `Ctrl+F` 直接打开APP内搜索
- **跨模块检索**：覆盖37个核心缩写、303条专业术语、36项材料管件图鉴、全部计算器、DN管径目录和主要页面
- **语境消歧**：例如搜索PT会同时提示渗透检测与部分培训资料中的螺纹法兰写法
- **结果直达**：点击结果自动打开对应资料卡、计算器、管径表或页面并短暂高亮

### 任务化首页
- **三种工作模式**：现场、学习、资料分别展示最常用入口，减少菜单往返
- **项目本与历史**：按学习者和项目自动保存最近计算摘要，可继续上次工作
- **学习总览**：集中显示空间闯关、专业课程和30天路线完成度
- **最近搜索**：资料模式记录缩写、材料和标准查询，可一键重新搜索
- **手套大按钮**：扩大输入框和主要按钮触控区域，适合现场单手操作
- **离线健康检查**：分别检查Three.js、WebGL、PDF、OCR Worker、中英文模型、WASM和本地存储

### 图文动画微课
- **5节离线短课**：方向坐标、单线图变3D、三通弯头方向、下料扣除、真实考试图拆解
- **逐步动画**：支持前后切换、自动播放和步骤圆点直达，不依赖网络视频
- **图文公式**：每一步同步显示示意图、文字要点和关键公式
- **小测解锁**：答对本课问题后才能标记完成，进度按学习者保存并同步首页
- **B站中文视频**：提供单线图轴测图、图标符号、净料计算、马鞍口和管道氩弧焊中文学习入口

### 材料与管件图鉴
- **识图符号基础**：管口、弯头和三通向上/向下/向北/向南的常见符号与空间外形并列显示
- **标高与尺寸速查**：TOP/COP/BOP关系图，以及DN15～DN600与NPS/英寸常用对照表
- **管径与弯头目录**：补充常用管外径及90°长半径/短半径弯头中心至端面参考值，可回填复合偏移计算
- **三通方向模拟**：切换支口向上、向下、向北、向南，对照E/N/EL坐标方向
- **国标与美标提示**：区分DN/PN和NPS/Class标记体系，列出现行管件与法兰标准
- **法兰双图识别**：WN、SO、PL、SW、TH、LJ、BL、IF同时显示实物外形与连接剖面
- **密封面图**：FF、RF、RTJ、MFM、TG配对与识别要点
- **常用材料标记**：碳钢、不锈钢的管材、管件和锻件常见牌号，明确不可直接等同代换
- **分类与全文搜索**：可按管件、法兰、密封面、材料和标准筛选，也可直接搜索代号或标准号
- **专业术语库**：303条中英术语覆盖管件、法兰垫片、阀门、附件、隔热伴热、材料、布置尺寸、图纸文件、操作参数、焊接和检验试验
- **多义缩写提示**：SW、SB、PT、CL、P、T等多义代号明确提示结合项目图例，不直接照搬来源资料中的错误释义
- **口试扩展**：从术语库筛选236个适合口试的缩写加入随机题库

## 技术栈

- **前端**：纯 HTML + CSS + JavaScript，无框架依赖
- **3D 渲染**：Three.js (r128)
- **PDF 渲染**：PDF.js（本地文件）
- **文字识别**：Tesseract.js（中英文离线模型）
- **数学计算**：expr-eval 表达式解析器
- **数据存储**：localStorage（支持导入导出）
- **打包工具**：HBuilderX（可选，用于安卓打包）

## 快速开始

### 本地运行

1. 克隆或下载本项目
```bash
git clone https://github.com/wangzhaoli93/pipe-isometric-trainer.git
cd pipe-isometric-trainer
```

2. 基础训练可直接用浏览器打开 `index.html`。图纸 PDF 与 OCR 功能建议使用本地服务器或打包后的 App，避免浏览器限制本地工作线程：
```bash
# Python 3
python -m http.server 8000

npx http-server -p 8000
```

3. 访问 `http://localhost:8000`

2. 打开项目目录
3. 发行 → 原生 App-云打包
4. 选择 Android 并配置证书
5. 打包生成 APK

## 使用说明

### 坐标练习

1. **选择案例**：从左侧面板选择预设案例或点击"随机题"
2. **观察单线图**：右侧显示等轴投影，虚线为地面投影
3. **计算坐标**：从起点开始，逐段累加 E、N、EL 坐标
4. **输入答案**：在"坐标练习"区域输入终点坐标
5. **核对结果**：点击"核对坐标"检查答案
6. **查看3D**：点击"显示3D"验证你的答案

### 导入图纸生成练习

1. 打开“图纸识别”，选择 JPG、PNG 或不超过 50 MB 的 PDF。
2. PDF 先点“读取PDF文字”；扫描图或照片点“OCR识别”。
3. 检查识别出的管线号、DN 和起点坐标，不正确时直接修改。
4. 点“手动标点”，沿管道中心线按起点、各转折点、终点依次点击；自动找长线仅用于辅助观察。
5. 在“路径确认”中逐段核对方向和尺寸，最后点“生成3D与单线图”。
6. 手机上可使用 `＋ / −` 或双指缩放图纸；放大后拖动画布，再点击中心线。倍率变化不会改变原图坐标和已有标点。

> 识别功能用于学习和建模草稿，不能作为下料、预制或现场施工依据。尺寸、坐标、坡度、管件和图纸版本均须人工复核。

### 学习教练与个性路线

1. 首页切换到“学习”，打开“学习教练”。
2. 完成 10 道入门题，覆盖方向坐标、空间识图、几何计算、图纸符号和现场施工。
3. 测评完成后查看五项能力、薄弱项和推荐路线；点击“专项练习”直接进入对应模块。
4. 后续在空间闯关、坐标练习、微课、缩写闯关或专业判断中答错，学习教练会自动更新错误归因和训练优先级。
5. 每个学习者的测评、错题和路线相互独立，可在“我的”中导出备份。

### 现场工作台

1. 首页“现场”选择或新建项目，打开“现场记录”。
2. 选择记录类型，填写位号、设计值、实测值、允许偏差；坐标和备注可按需要填写。
3. 保存后系统自动计算偏差并标记“合格”或“超差”；需要再次确认的记录可标为“待复测”。
4. 使用“全部、超差、待复测”快速筛选，复测完成后点击“完成复测”。
5. 点击“导出报告”生成离线 HTML 文件，可用浏览器查看、打印或另存为 PDF。

### 计算报告

1. 打开任意放样计算器并填写参数。
2. 核对已知条件、单位、公式说明和计算结果。
3. 点击页面右上角“导出当前报告”，报告会包含当前项目、输入条件、计算结果及安全提示。

> 导出的计算和现场记录是学习、复核草稿，不能替代设计文件、施工方案、质量验收表或责任人员签认。

## 开发说明

### 代码结构

- `app.js`：主应用逻辑，包含状态管理、3D 渲染、计算器等
- `styles.css`：响应式布局，支持桌面和移动端
- 使用 IIFE 模式避免全局污染

### 性能优化

- Three.js 按需渲染，仅在场景变化时重绘
- 几何体和材质缓存，减少内存占用
- DOM 查询缓存，提升访问速度

### 添加新案例

在 `app.js` 的 `presets` 对象中添加新案例：

```javascript
const presets = {
  myCase: {
    start: [0, 0, 0],  // 起点 [E, N, EL]
    dn: 100,            // 管径
    segments: [         // 管段列表
      { dir: 'E', length: 1000 },           // 方向 + 长度
      { dir: 'XYZ', dx: 500, dy: 300, dz: 200 }  // 自定义偏移
    ]
  }
};
```

然后在 HTML 中添加对应的按钮：

```html
<button class="preset-btn" data-preset="myCase" data-case-group="common">
  13 · 我的案例
</button>
```
