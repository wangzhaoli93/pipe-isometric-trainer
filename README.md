# 管线空间训练器 (Pipe Isometric Trainer)

一个用于管道工、管工学徒和相关工程人员的交互式学习工具，帮助训练空间想象力、坐标计算能力和单线图识读技能。

## 功能特性

### 三维训练器
- **12 个预设案例**：从简单的立管转向到复杂的空间偏移
- **实时 3D 可视化**：基于 Three.js 的交互式三维管道展示
- **等轴投影单线图**：自动生成二维单线图，带地面投影参考
- **坐标练习模式**：隐藏 3D 视图，训练从单线图推算终点坐标
- **案例收藏与错题记录**：支持多学习者档案，独立保存进度

### 专业模块
- **5 大专业方向**：石油管线、化工管线、模块化施工、管道预制、改造与切割
- **20 节系统课程**：每节包含学习要点、操作步骤和现场检查点
- **现场判断题**：模拟真实工程场景的安全与质量判断

### 工程计算器
- **空间角度计算**：坐标差计算平面偏移、真长、方向角和坡度
- **来回弯计算**：S 形偏移的斜长、水平占用和弯头切线长
- **弯头下料**：中心半径、切线长、弧长和弦长计算
- **死口/活口闭合**：闭合管段的净下料长度计算
- **斜接弯头**：等角斜接弯头的接缝角度和退切量
- **马鞍口展开**：90° 支管马鞍口的相贯线放样
- **改造对比**：旧管实测与新设计的尺寸对比

### 随手算工具
- **表达式计算**：支持三角函数、开方、幂运算
- **圆与圆周**：半径、直径、周长、面积互算
- **直角三角形**：勾股定理和角度计算
- **管道计算**：周长、外表面积、容积和理论重量
- **单位换算**：长度和压力单位转换

### 学习路线
- **30 天学习计划**：从坐标基础到图纸对应现场
- **16 个关键技能点**：可勾选追踪完成进度
- **速查表**：常见缩写、图纸类型和施工标记

## 技术栈

- **前端**：纯 HTML + CSS + JavaScript，无框架依赖
- **3D 渲染**：Three.js (r128)
- **数学计算**：expr-eval 表达式解析器
- **数据存储**：localStorage（支持导入导出）
- **打包工具**：HBuilderX（可选，用于安卓打包）

## 快速开始

### 本地运行

1. 克隆或下载本项目
```bash
git clone https://github.com/YOUR_USERNAME/pipe-isometric-trainer.git
cd pipe-isometric-trainer
```

2. 直接用浏览器打开 `index.html`，或使用本地服务器：
```bash
# Python 3
python -m http.server 8000

# Node.js (需要安装 http-server)
npx http-server -p 8000
```

3. 访问 `http://localhost:8000`

### 安卓应用（可选）

本项目已配置 HBuilderX 的 manifest.json，可以打包为安卓应用：

1. 安装 [HBuilderX](https://www.dcloud.io/hbuilderx.html)
2. 打开项目目录
3. 发行 → 原生 App-云打包
4. 选择 Android 并配置证书
5. 打包生成 APK

详细说明参见 [README-安卓打包.md](./README-安卓打包.md)

## 使用说明

### 坐标练习

1. **选择案例**：从左侧面板选择预设案例或点击"随机题"
2. **观察单线图**：右侧显示等轴投影，虚线为地面投影
3. **计算坐标**：从起点开始，逐段累加 E、N、EL 坐标
4. **输入答案**：在"坐标练习"区域输入终点坐标
5. **核对结果**：点击"核对坐标"检查答案
6. **查看3D**：点击"显示3D"验证你的答案

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `N` | 新增管段 |
| `R` | 随机题 |
| `F` | 适配视图 |
| `←` | 上一段 |
| `→` | 下一段 |
| `Esc` | 退出练习模式 |

### 暗色模式

- 点击右上角 ◐ 按钮切换暗色模式
- 自动检测系统主题设置
- 设置会保存到本地

## 开发说明

### 代码结构

- `app.js`：主应用逻辑，包含状态管理、3D 渲染、计算器等
- `styles.css`：响应式布局，支持桌面和移动端
- 使用 IIFE 模式避免全局污染

### 性能优化

- Three.js 按需渲染，仅在场景变化时重绘
- 几何体和材质缓存，减少内存占用
- DOM 查询缓存，提升访问速度

### 添加新案例

在 `app.js` 的 `presets` 对象中添加新案例：

```javascript
const presets = {
  myCase: {
    start: [0, 0, 0],  // 起点 [E, N, EL]
    dn: 100,            // 管径
    segments: [         // 管段列表
      { dir: 'E', length: 1000 },           // 方向 + 长度
      { dir: 'XYZ', dx: 500, dy: 300, dz: 200 }  // 自定义偏移
    ]
  }
};
```

然后在 HTML 中添加对应的按钮：

```html
<button class="preset-btn" data-preset="myCase" data-case-group="common">
  13 · 我的案例
</button>
```
