# 管线空间训练器 - HBuilderX 安卓打包

本目录已经是一个可离线运行的 `5+ App` 项目。三维库、页面、样式和训练数据均在项目内，生成的 App 不需要联网。

## 第一次打开

1. 启动 HBuilderX，登录 DCloud 账号。
2. 选择 `文件 -> 打开目录`，打开整个 `pipe-isometric-trainer` 文件夹，不要只打开 `index.html`。
3. 在项目管理器中双击 `manifest.json`。
4. 在“基础配置”中点击“重新获取 AppID”或“获取 AppID”，保存。
5. 应用名称填写“管线空间训练器”，版本名称保持 `1.18.1`，版本号保持 `1181`。

## 1.2 学习内容

- “训练器”：练习 E、N、EL 坐标、单线图和三维走向。
- “空间闯关”：6级36题，从方向判断逐步练到带尺寸线、投影和焊口干扰的考试图；支持示意/真实比例、图层开关、点击路径、逐段坐标讲解和可旋转3D。
- “图纸识别”：导入 JPG、PNG 或 PDF，读取文字、标记中心线、人工确认路径后生成 3D 与单线图。
- “铁丝实操”：随机隐藏 3D，按单线图弯铁丝并完成四项自检后显示答案。
- “专业模块”：包含石油管线、化工管线、模块化施工、管道预制、改造与切割，共 20 课及 15 道现场判断题。
- “放样计算”：包含勾股与三角、复合滚动偏移、坡度与测点标高、直管下料与焊口组对；同时包含来回弯、弯头扣除、死口/活口闭合、斜接弯头、90°马鞍口展开和旧管改造对比。
- “学习路线”：记录 30 天基础训练进度。
- “速查表”：查询现场常见英文缩写和图纸标记，并进行每轮 10 题的缩写闯关。
- “资料”中的材料与管件图鉴可查询管口/弯头/三通方向符号、TOP/COP/BOP、DN与英寸对照、法兰外形和剖面、密封面、材料标记及国标/美标标准号。
- 标题栏“⌕”可全局搜索英文缩写、图鉴、计算器和DN目录；连接键盘时也可使用 `Ctrl+F`。
- 首页按“现场、学习、资料”组织任务，并提供项目计算历史、手套大按钮和离线资源检查；项目本会随学习数据一起导出备份。
- 首页“学习”中的图文动画课包含5节离线微课、逐步播放、小测和学习进度；官方在线资料需要联网打开。
- 首页“学习教练”提供五类能力测评、错题归因、薄弱项和个人推荐路线；空间题、微课、缩写题及专业判断错误会自动汇总。
- “现场工作台”按项目保存管口、坐标点、支架、焊口和标高记录，自动判断允许偏差并管理待复测状态。
- 工程计算与现场记录均可导出离线HTML报告，可在手机或电脑浏览器中查看、打印或另存为PDF。
- 手机端使用“学习、练图、计算、资料、我的”底部导航；桌面端保留顶部导航。
- 全局“123”计算器支持安全算式解析、角度模式、圆、直角三角形、管道重量/容积及长度/压力换算，并可将结果回填到最近使用的数值框。
- “我的”支持多个本地学习者、独立进度、案例收藏、错题记录以及学习数据导入导出。
- 训练器自动保存当前草稿，重新打开或切换学习者后恢复；参数修改支持撤销与重做。
- 首页项目本会保存计算器完整输入参数，点击最近记录可继续上次计算。
- Three.js、PDF.js 和 OCR 按功能需要加载，减少首页启动占用；安卓返回键优先关闭弹层、返回上一页，再次按键退出。
- Three.js 使用单位圆柱几何复用与事件驱动渲染；离开训练页或空闲时停止请求动画帧。
- 主题支持系统自动检测和手动覆盖，Three.js背景及参考面同步切换。
- 导入数据限制为1MB，校验版本与结构，写入失败时自动回滚。
- 图纸文件限制为50MB。OCR、PDF渲染和中英文模型均随 App 本地打包，首次识别可能等待数秒。
- 自动提取与自动找线只提供候选，所有尺寸、坐标、方向、管件和图纸版本必须对照原图人工确认，不能直接作为施工或下料依据。

## 横屏训练

- 训练器包含 12 种案例，其中 6 种常用案例、6 种特殊案例；参数区的每一部分都可以用 `+ / −` 折叠或展开。
- 手机开启自动旋转后直接横放，会自动切换为左侧数据、中间 3D、右侧单线图。
- APK 内可点击标题旁的“横屏”按钮切换方向；横屏工具栏的“数据”和“单线”按钮可分别隐藏对应面板。
- 普通浏览器不允许自动旋转时，点击按钮后按提示手动横放手机。

专业模块的勾选进度保存在手机本地。卸载 App、清除应用数据或更换测试证书重新安装时，进度可能被清除。

## 1.18 新功能使用

### 学习教练

1. 首页选择“学习 -> 学习教练”。
2. 完成 10 道能力测评题，系统会生成五项能力图。
3. 点击薄弱项后的“专项练习”进入对应训练。
4. 后续答错的空间题、微课、缩写题和专业判断题会自动进入错误归因。

### 现场记录

1. 首页“现场”中先选择或新建项目，再点击“现场记录”。
2. 填写位号、设计值、实测值、允许偏差、坐标或备注。
3. 保存后查看合格、超差和待复测状态。
4. “导出报告”生成 HTML 文件，可传到电脑打印或在浏览器中另存为 PDF。

### 数据备份

在“我的 -> 数据管理”中导出学习数据。备份包含学习测评、错误归因、训练草稿、项目计算和现场记录；升级或更换手机前建议先导出。

## 配置图标

1. 打开 `manifest.json` 的“App 图标配置”。
2. 选择项目中的 `icon-512.png`。
3. 使用 HBuilderX 的“自动生成所有图标”功能。

## 先在手机上测试

1. 安卓手机打开“开发者选项”和“USB 调试”。
2. 用数据线连接电脑，允许本机调试。
3. 在 HBuilderX 中选择 `运行 -> 运行到手机或模拟器 -> 运行到 Android App 基座`。
4. 检查三维旋转、坐标输入、随机题、学习进度和返回键。

## 生成 APK

1. 选中项目根目录。
2. 选择 `发行 -> 原生 App-云打包`。
3. 平台选择 Android，包名可使用 `com.pipeiso.trainer`，也可以换成自己的唯一包名。
4. 仅自己测试时，可以先选择公共测试证书；长期安装、更新或对外发布时，应使用自己的安卓签名证书。
5. 勾选“安心打包”后提交。
6. 打包完成后，APK 通常保存在项目的 `unpackage/release/apk/` 目录。

## 签名注意事项

- 正式使用时要创建并妥善保存自己的签名文件、别名和密码。
- 同一个 App 后续升级必须使用同一份签名；签名丢失后不能覆盖安装旧版本。
- 公共测试证书适合临时试装，不适合发布应用市场。

## 常见问题

### HBuilderX 没把目录识别成 5+ App

在 HBuilderX 中新建一个“5+ App 默认模板”，获取 AppID 后，将本目录中的 `index.html`、`styles.css`、`app.js`、`vendor` 和 `icon-512.png` 复制到新项目，并保留新项目生成的 `manifest.json`。

### 打包后打开是空白页

确认 `vendor/three.min.js` 和 `vendor/OrbitControls.js` 都存在，并且 `manifest.json` 的启动页面为 `index.html`。

### 三维画面卡顿

将安卓系统中的电池优化关闭，或在浏览器/系统设置中确认 WebView 已更新。训练器会自动限制渲染分辨率，不需要额外插件。

### 手机没有电脑时怎么安装

把生成的 APK 发到手机，打开文件后按系统提示允许“安装未知应用”。只安装自己打包或可信来源的 APK。

### OCR提示失败

`1.18.1` 已针对安卓 `file://` WebView 改为本地 Worker 和内嵌 WASM Core优先，并在失败时自动切换第二种加载方式。重新打包后请先在首页运行“离线资源检查”；如果仍失败，记录页面显示的完整失败阶段，不再只显示 `undefined`。

### 图纸太小，无法准确标点

图纸工具栏提供 `− / 当前倍率 / ＋ / 适配图纸`。手机可双指缩放，放大后拖动画布到目标位置，再开启“手动标点”。缩放只改变显示尺寸，不会改变已标记点对应的原图坐标。
