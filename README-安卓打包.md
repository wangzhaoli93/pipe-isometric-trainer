# 管线空间训练器 - HBuilderX 安卓打包

本目录已经是一个可离线运行的 `5+ App` 项目。三维库、页面、样式和训练数据均在项目内，生成的 App 不需要联网。

## 第一次打开

1. 启动 HBuilderX，登录 DCloud 账号。
2. 选择 `文件 -> 打开目录`，打开整个 `pipe-isometric-trainer` 文件夹，不要只打开 `index.html`。
3. 在项目管理器中双击 `manifest.json`。
4. 在“基础配置”中点击“重新获取 AppID”或“获取 AppID”，保存。
5. 应用名称填写“管线空间训练器”，版本名称保持 `1.5.2`，版本号保持 `152`。

## 1.2 学习内容

- “训练器”：练习 E、N、EL 坐标、单线图和三维走向。
- “专业模块”：包含石油管线、化工管线、模块化施工、管道预制、改造与切割，共 20 课及 15 道现场判断题。
- “放样计算”：包含空间/滚动偏移、来回弯、弯头扣除下料、死口/活口闭合、斜接弯头、90°马鞍口展开和旧管改造对比；每项带公式、步骤和现场注意。
- “学习路线”：记录 30 天基础训练进度。
- “速查表”：查询现场常见英文缩写和图纸标记。
- 手机端使用“学习、练图、计算、资料、我的”底部导航；桌面端保留顶部导航。
- 全局“123”计算器支持安全算式解析、角度模式、圆、直角三角形、管道重量/容积及长度/压力换算，并可将结果回填到最近使用的数值框。
- “我的”支持多个本地学习者、独立进度、案例收藏、错题记录以及学习数据导入导出。
- Three.js 使用单位圆柱几何复用与事件驱动渲染；离开训练页或空闲时停止请求动画帧。
- 主题支持系统自动检测和手动覆盖，Three.js背景及参考面同步切换。
- 导入数据限制为1MB，校验版本与结构，写入失败时自动回滚。

## 横屏训练

- 训练器包含 12 种案例，其中 6 种常用案例、6 种特殊案例；参数区的每一部分都可以用 `+ / −` 折叠或展开。
- 手机开启自动旋转后直接横放，会自动切换为左侧数据、中间 3D、右侧单线图。
- APK 内可点击标题旁的“横屏”按钮切换方向；横屏工具栏的“数据”和“单线”按钮可分别隐藏对应面板。
- 普通浏览器不允许自动旋转时，点击按钮后按提示手动横放手机。

专业模块的勾选进度保存在手机本地。卸载 App、清除应用数据或更换测试证书重新安装时，进度可能被清除。

## 配置图标

1. 打开 `manifest.json` 的“App 图标配置”。
2. 选择项目中的 `icon-512.png`。
3. 使用 HBuilderX 的“自动生成所有图标”功能。

## 先在手机上测试

1. 安卓手机打开“开发者选项”和“USB 调试”。
2. 用数据线连接电脑，允许本机调试。
3. 在 HBuilderX 中选择 `运行 -> 运行到手机或模拟器 -> 运行到 Android App 基座`。
4. 检查三维旋转、坐标输入、随机题、学习进度和返回键。

## 生成 APK

1. 选中项目根目录。
2. 选择 `发行 -> 原生 App-云打包`。
3. 平台选择 Android，包名可使用 `com.pipeiso.trainer`，也可以换成自己的唯一包名。
4. 仅自己测试时，可以先选择公共测试证书；长期安装、更新或对外发布时，应使用自己的安卓签名证书。
5. 勾选“安心打包”后提交。
6. 打包完成后，APK 通常保存在项目的 `unpackage/release/apk/` 目录。

## 签名注意事项

- 正式使用时要创建并妥善保存自己的签名文件、别名和密码。
- 同一个 App 后续升级必须使用同一份签名；签名丢失后不能覆盖安装旧版本。
- 公共测试证书适合临时试装，不适合发布应用市场。

## 常见问题

### HBuilderX 没把目录识别成 5+ App

在 HBuilderX 中新建一个“5+ App 默认模板”，获取 AppID 后，将本目录中的 `index.html`、`styles.css`、`app.js`、`vendor` 和 `icon-512.png` 复制到新项目，并保留新项目生成的 `manifest.json`。

### 打包后打开是空白页

确认 `vendor/three.min.js` 和 `vendor/OrbitControls.js` 都存在，并且 `manifest.json` 的启动页面为 `index.html`。

### 三维画面卡顿

将安卓系统中的电池优化关闭，或在浏览器/系统设置中确认 WebView 已更新。训练器会自动限制渲染分辨率，不需要额外插件。

### 手机没有电脑时怎么安装

把生成的 APK 发到手机，打开文件后按系统提示允许“安装未知应用”。只安装自己打包或可信来源的 APK。
