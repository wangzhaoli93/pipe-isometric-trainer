      详细计算说明

      适用

      两个坐标点之间的空间直管、滚动偏移及坡度复核。

      计算顺序

      1. 先用 ΔE、ΔN 求平面偏移。
      2. 再把平面偏移与 ΔEL 组成直角三角形，求空间真长。
      3. 方向角从 E+ 轴转向 N+ 轴计量；坡度角由高差与平面偏移计算。

      平面偏移 = √(ΔE² + ΔN²)
      空间真长 = √(ΔE² + ΔN² + ΔEL²)

      图纸斜线不一定是斜管，必须同时看到坐标、高差或角度依据。

        什么时候用哪个公式

        两条直角边已知：用勾股定理求斜边，再用 atan 求角度。

        斜边和一条直角边已知：先用勾股定理反求另一边，再用 asin 或 acos 求角度。

        一个锐角和一条边已知：对边/邻边用 tan，对边/斜边用 sin，邻边/斜边用 cos。

        C = √(A²+B²)
        θ = atan(B÷A)
        sinθ = B÷C · cosθ = A÷C · tanθ = B÷A

        现场先确认尺寸是中心线尺寸还是端面尺寸；计算出的中心线斜长不能直接替代扣除弯头后的直管下料长度。

        详细计算说明

        偏心距

        两条平行管道中心线之间的垂直距离，不是两根管外壁的净距。

        计算步骤

        1. 用偏心距和弯头角度求斜管中心线长度。
        2. 用弯头中心半径求每只弯头的切线占用。
        3. 斜长减去两端切线长，得到中间直管参考长度。

        斜长 = 偏心距 ÷ sinθ
        水平占用 = 偏心距 ÷ tanθ
        切线长 = R × tan(θ÷2)
        中间直管 = 斜长 - 2×切线长

        R必须取实际管件中心半径；直管下料还要考虑坡口、焊口间隙和实物尺寸。

        详细计算说明

        本工具的定义

        死口表示两端都不能移动，尺寸必须按最终实测闭合；活口表示至少一端允许按批准方法调整，因此可预留少量现场修切量。

        计算步骤

        1. 用三个坐标差计算接口中心真距。
        2. 扣除A、B两端从接口中心到焊口端面的占用。
        3. 再扣除WPS规定的焊口间隙合计。
        4. 活口毛坯在理论长度上增加预留修切量。

        净下料 = 中心真距 - A端占用 - B端占用 - 间隙合计

        死口不得用倒链或加热强拉设备口；实际下料必须在隔离、支撑和最终接口复测完成后进行。
